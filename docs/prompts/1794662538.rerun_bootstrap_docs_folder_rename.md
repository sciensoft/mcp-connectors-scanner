# Request

Re-run the bootstrap on the scanner repository with the newer version (2026-10-24), applying only the change that version brings, before the repository gets more content.

## Reasoning

The scaffold was written from version 2026-09-16. The owner published 2026-10-24 the same day. Its one change: the hidden `.docs/` folder becomes a visible `docs/` folder, for ADRs, prompts, todos and the security methodology. Reasons given upstream: `docs/` is where readers and GitHub Pages look, and dotted folders are collapsed by many file explorers.

The bootstrap says to stop and ask when `docs/` already exists with unrelated content. It did here: the guide and decision log live in `docs/`. The two did not overlap, because none of `docs/adrs`, `docs/prompts`, `docs/todos`, `docs/security` existed, so the four folders moved in beside the guide and decision log with `git mv`, and history follows.

Only the scanner repository was migrated. The private application repository gets the new bootstrap file now and its own migration after the scanner work is finished, by the owner's decision.
